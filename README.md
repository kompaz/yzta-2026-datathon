# YZTA 2026 Datathon

This repository contains the data science workflow developed for the YZTA 2026 Datathon competition.

## Problem Definition

The task is a regression problem. The objective is to predict the cognitive performance score:

```text
bilissel_performans_skoru
```

using sleep, stress, lifestyle, demographic, and health-related features.

## Workflow

The project follows this workflow:

1. Exploratory Data Analysis
2. Baseline modeling
3. Feature engineering
4. CatBoost tuning
5. LightGBM and XGBoost tuning
6. Extra regression model experiments
7. Native categorical CatBoost modeling
8. Weighted ensemble and Ridge stacking

## Best Local Validation Result

The best local validation result was obtained with a weighted ensemble of CatBoost-based models.

```text
Best local CV RMSE: 1.215972
```

The strongest single model was:

```text
catboost_native_depth4
Local CV RMSE: approximately 1.21655
```

## Main Techniques Used

- Missing value imputation
- Feature engineering
- CatBoost native categorical handling
- CatBoost, LightGBM and XGBoost tuning
- Extra regression model experiments
- Weighted blending
- Ridge stacking

## Data Notice

Competition data files are not included in this repository.

To run the notebooks, place the following files under the `data/` directory:

```text
data/train.csv
data/test_x.csv
data/sample_submission.csv
```

These files are ignored by Git using `.gitignore`.
